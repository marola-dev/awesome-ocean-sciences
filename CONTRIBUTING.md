# Contributing

Open a pull request that adds one entry per line, in the section it fits:

```
- [Name](https://canonical-url) - What it is, in one sentence ending with a period.
```

- Link the project's own homepage or repository, not an article about it.
- Describe the project, not the list; no marketing words.
- Add `Updated YYYY-MM-DD` after the description of every GitHub repository: the `pushed_at` date of the upstream repository on the day you checked it. For a fork, link the upstream, never the fork.
- Name the licence in brackets when it limits reuse (non-commercial weights, copyleft).
- Open the link yourself before adding it. A dead or redirected link is a bug: fix or remove it.
- Brazil and the South Atlantic have their own section; other regions are welcome in the general ones.
- Instagram entries are account profiles (`https://www.instagram.com/<handle>/`), never reels or posts; add a one-line description and keep each group alphabetical.
